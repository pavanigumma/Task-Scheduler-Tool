## PROJECT OVERVIEW
The **Smart Task Scheduler Tool** is an interactive, web-based productivity application built using **Python** and **Streamlit**. Designed for students, software engineering interns, and project leads, this tool simplifies personal time management by enabling users to schedule, categorize, prioritize, and track pending deliverables in real time.

The application eliminates administrative tracking overhead by offering dynamic status tracking, immediate filter capabilities, and high-priority deadline monitoring through interactive visual metrics.

---

## KEY FEATURES & CAPABILITIES
* **Real-time Task KPI Dashboard:** Metrics overview displaying total task volume, completed tasks, ongoing items, and urgent high-priority flags.
* **Multi-Criteria Task Querying:** Filter scheduled items by completion progress (**Pending**, **In Progress**, **Completed**) or target importance level (**High**, **Medium**, **Low**).
* **Interactive Task Scheduling Form:** Add new tasks with calendar date selectors, category assignments, and input validation.
* **Dynamic Status Updating:** Instantly update progress flags for active deliverables using Streamlit session state memory.
* **Date Restrictions:** Integrated calendar control enforcing valid execution dates.
